# 🚀 Algoritmos e Estruturas de Dados

Repositório desenvolvido durante o projeto **Do Zero ao Estágio**, com o objetivo de estudar algoritmos, estruturas de dados e construir uma base sólida para o desenvolvimento Back-End.

---

# 🎯 Objetivos

- Aprender estruturas de dados do zero
- Implementar algoritmos clássicos
- Desenvolver mini projetos utilizando cada estrutura
- Construir um portfólio organizado e profissional
- Evoluir até um projeto completo de software
