# Stack (Pilha)

## 📖 Sobre

Stack é uma estrutura de dados do tipo LIFO (Last In, First Out), onde o último elemento inserido é o primeiro a ser removido.

## 🎯 Objetivo

Implementar uma pilha do zero para compreender operações de inserção, remoção e aplicações práticas.

## 🚀 Aplicações

- Desfazer ações (Undo)
- Histórico de Navegação
- Validação de Expressões
