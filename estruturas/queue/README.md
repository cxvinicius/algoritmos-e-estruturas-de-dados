# Queue (Fila)

## 📖 Sobre

Queue é uma estrutura de dados do tipo FIFO (First In, First Out), onde o primeiro elemento inserido é o primeiro a ser removido.

## 🎯 Objetivo

Implementar uma fila do zero para compreender gerenciamento de ordem e processamento sequencial.
