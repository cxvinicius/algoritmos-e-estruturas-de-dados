# Hash Table

## 📖 Sobre

Hash Tables armazenam pares chave-valor utilizando uma função hash para permitir buscas rápidas.

## 🎯 Objetivo

Implementar uma Hash Table do zero para compreender indexação, colisões e acesso eficiente aos dados.
